RingtoneComposer
================

> **This project has been rewritten.** The new version is an installable web app, with a Nokia 3310 retro mode and a piano mode:
>
> - Code: <https://github.com/skacofonix/ringtone-composer>
> - Try it: <https://skacofonix.github.io/ringtone-composer/>
>
> This repository (C# / Xamarin, 2015) is kept for history and is no longer maintained.

Ringtone composer based on RTTL format (like Nokia 3310). Xamarin cross-plateform application targeted for Windows Phone, Android and iPhone.

# Features
- Parse RTTL / Parse Nokia Composer / Nokia Keypress
- Generate RTTL / Parse Nokia Composer / Nokia Keypress
- Convert RTTL / Nokia Composer / Nokia Keypress ==> RTTL / Nokia Composer / Nokia Keypress
- Generate Wave
